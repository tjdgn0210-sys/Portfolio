What it does

영상을 넣으면, 나머지는 프로그램이.

말이 없는 구간을 자르고, 목소리를 자막으로 만들고, 가로 영상을 쇼츠로 바꿉니다. 모든 처리는 내 PC 안에서 이루어집니다.

    옵션 화면을 단순화해 재현했습니다. mp4 이름 규칙(_edited, _subtitled, _video)은 실제 코드의 규칙을 따랐고, srt·wav 이름과 ‘강의’라는 파일명은 예시입니다.

    Feedback

    쓰는 사람의 말이 기본값이 됐습니다.

    사용자“선택할 게 너무 많다”
    →
    결정옵션 화면을 카드 2개로 줄이고, 세부 선택은 둘 중 하나로
    사용자“mp4가 나오면 소리가 따로 나와서 불편”
    →
    결정기본값을 ‘소리 합치기 + 자막 입히기’로 뒤집음
    사용자기존 기능은 지우지 말아 달라
    →
    결정화면에서는 숨기고, 명령줄 옵션으로 남김

    Build

    보이지 않는 곳을 더 단단하게.

    4,544줄 · 화면(GUI) 코드
    1,662줄 · 컷·자막·쇼츠 처리 코드
    exe설치 없이 실행되는 Windows 프로그램
    KO / EN한국어·영어 화면, 다크 모드
    여러 줄 자막도 하나의 둥근 박스줄마다 박스가 겹쳐 진한 선이 생기던 문제를, 박스를 직접 그려서 해결
    작업 중 검은 창이 뜨지 않게모든 실행 경로에서 터미널 창을 숨겨, 놀라지 않도록
    그래픽카드가 없어도GPU 인코딩을 먼저 시험하고, 안 되면 CPU로 자동 전환
    남은 시간이 맞아지도록PC별 처리 속도를 학습해 진행률을 보정

    Python · tkinter · FFmpeg · faster-whisper · PyInstaller. 줄 수는 2026-10-26 저장소 기준입니다.
